## 项目简介
Zcubed 是一款面向移动端的特色输入法，将英语学习功能融入日常输入场景。
在正常打字的同时，键盘可以实时展示对应英文释义，支持单词朗读、例句查看、整句翻译等能力。无需单独拿出时间背单词，利用聊天、搜索、记录文本等碎片化输入场景，潜移默化积累英文词汇。

## 核心功能
- ✅ 基础中文输入，保留常规输入法全部能力，可作为主力输入法使用
- ✅ 实时中英对照：输入中文，键盘上方自动展示对应的英文翻译
- ✅ 快捷操作：上滑快速输入英文；长句输入时右滑空格触发整句翻译
- ✅ 单词详情：长按单词查看释义、动词变形、近义词与配套例句，支持语音朗读
- ✅ 多套键盘主题：纯白、纯黑、复古终端、白粉、黑粉等样式自由切换
